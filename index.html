Understanding Cloud Computing

Explore the fundamental service models that power modern digital infrastructure.

IaaS

Infrastructure as a Service

Provides virtualized computing resources over the internet such as virtual servers, storage, and networking.

  • ✔️ Complete OS control
  • ✔️ Virtual Machines (VMs)
  • ✔️ Scalable Storage & VPCs
Examples: AWS EC2, Azure VMs, Google Compute Engine
PaaS

Platform as a Service

Provides a hardware and software framework for developers to build, test, and deploy applications effortlessly.

  • ✔️ Automated runtime management
  • ✔️ Integrated databases & tools
  • ✔️ Zero infrastructure overhead
Examples: Heroku, AWS Elastic Beanstalk, Google App Engine
SaaS

Software as a Service

Delivers fully managed, ready-to-use software applications directly through a web browser.

  • ✔️ No installation required
  • ✔️ Subscription-based access
  • ✔️ Automatic updates
Examples: Google Workspace, Microsoft 365, Salesforce
FaaS / Serverless

Function as a Service

Executes application logic on demand in response to events without maintaining persistent servers.

  • ✔️ Event-driven execution
  • ✔️ Pay strictly per millisecond
  • ✔️ Auto-scales from 0 to thousands
Examples: AWS Lambda, Azure Functions, Cloud Functions
